# Acceptance criteria

## Phase 0

- Mở app local thấy editor, source map, agent và version controls.
- Tạo project, lock brief, chạy local agent, chỉnh patch, restore version và export JSON được.
- Reload giữ state local khi storage hoạt động.
- `npm run check`, `npm test`, `npm run build` pass.
- UI và docs nói rõ local-first; không claim integration chưa có.

## Tổng sản phẩm

Chỉ release public SaaS sau khi auth/workspace/RLS, upload/ingestion, AI/provider, editor, patch/version, PPTX, Canva, admin/credits, security/evals, E2E và production rollback đều có evidence riêng.
