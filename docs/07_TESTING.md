# Testing strategy

Phase 0: syntax check, environment contract, architecture smoke test, RLS contract lint, Presentation JSON validation, reproducible static build và manual browser acceptance.

Phase sau phải bổ sung schema/patch contract tests, reducer/layout tests, parser fixtures, RLS isolation, integration mocks, visual regression, E2E upload-to-export và AI eval factual preservation/scope adherence.

Không đánh dấu production-ready chỉ vì local UI chạy được.
