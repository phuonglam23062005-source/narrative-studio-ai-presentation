# AI pipeline

FILES_ONLY là mặc định. Source content được delimit và coi là untrusted. Interview chỉ hỏi gap chưa biết; brief phải được user confirm trước generation.

Provider adapter phải trả structured output qua schema validation. Model không được trả HTML/PPTX làm nguồn sự thật. Tác vụ deterministic như overflow, contrast, geometry và chart mapping ưu tiên rule code.

Local phase dùng local composer deterministic trong browser: phân tích preview được phép đọc, tạo fact candidates có sourceRef và compose deck từ layout grammar. Đây là fallback có provenance chứ không phải model AI thật. Provider thật, quota, retry, queue và server-side validation thuộc phase sau.
